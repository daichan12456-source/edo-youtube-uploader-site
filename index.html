Edo YouTube Uploader

自分が所有する YouTube チャンネルに動画をアップロード・予約投稿するための、個人用のデスクトップ ツールです。

ホーム プライバシーポリシー 利用規約

このツールについて

Edo YouTube Uploader は、制作者本人が所有する YouTube チャンネルに、完成した動画ファイルを アップロードし、公開日時を予約するための Windows 用コマンドライン ツールです。 制作者本人の個人的な利用のみを目的としており、一般に配布していません。

動画は必ず非公開（private）としてアップロードされます。あわせて、あらかじめ 人が決めておいた公開日時を設定し、その日時になると YouTube の機能によって自動的に公開されます。 本ツールが動画をその場で一般公開することはなく、公開日時はツールが判断するのではなく、 事前に用意した予定表から読み取ります。

できること

  • 手元にある動画ファイルを、本人のチャンネルに非公開でアップロードする
  • タイトル・説明文・タグ・公開予定日時を、あらかじめ用意した設定どおりに登録する
  • アップロードした動画が設定どおりに登録されたかを読み取って確認する
  • 同じ動画を二重にアップロードしないよう、送信済みの記録と照合する

できないこと

  • 本人以外のチャンネルを操作すること
  • 動画を自動で一般公開すること
  • 他の利用者の情報を取得・保存・共有すること

使用している Google / YouTube のサービス

本ツールは YouTube Data API v3 を利用しています。取得する情報と利用目的は プライバシーポリシーに記載しています。

本ツールの利用には、YouTube の利用規約および Google プライバシーポリシーが適用されます。
