Edo YouTube Uploader

ホーム プライバシーポリシー 利用規約

1. 位置づけ

Edo YouTube Uploader（以下「本ツール」）は、制作者本人が自分の YouTube チャンネルを 操作するために作った個人用のツールです。一般に配布しておらず、制作者本人以外の利用者を 想定していません。商用のサービスとして提供するものではありません。

2. 利用条件

  • 本ツールを利用できるのは、制作者本人、および制作者が個人的に知っている ごく少数の関係者に限られます。
  • 本ツールは、利用者自身が権利を持つチャンネルおよび動画に対してのみ使用できます。
  • 本ツールの利用には、 YouTube の利用規約、 YouTube API サービス デベロッパー ポリシー、 および Google プライバシーポリシーが適用されます。 利用者はこれらを遵守するものとします。

3. 禁止事項

  • 他人が権利を持つチャンネルや動画に対して本ツールを使用すること
  • 法令、YouTube の規約、または Google の各種ポリシーに反する内容の動画を 本ツールによって投稿すること
  • 取得した認証情報を第三者に渡すこと

4. 動画の公開について

本ツールは、動画を必ず非公開（private）としてアップロードします。 あわせて公開予定日時を設定し、その日時になると YouTube の機能によって自動的に公開されます。 設定した日時が来るまで動画は公開されません。公開日時は、あらかじめ人が用意した予定表から 読み取るものであり、本ツールが日時を判断したり、その場で一般公開したりすることはありません。

5. 免責

  • 本ツールは現状有姿で提供され、特定の目的への適合性を含め、いかなる保証もありません。
  • 本ツールの利用、または利用できなかったことにより生じた損害について、 制作者は責任を負いません。
  • YouTube Data API の仕様変更、障害、利用上限、または Google による アカウントの措置に起因する不具合について、制作者は責任を負いません。
  • 投稿した動画の内容および権利処理については、投稿した本人が責任を負います。

6. 変更と終了

本ツールおよび本規約は、予告なく変更または提供を終了することがあります。 変更した場合は、このページを更新し、最終更新日を改めます。

7. お問い合わせ

お問い合わせは、本ツールの Google OAuth 同意画面に表示される ユーザー サポートメールまでお願いします。
