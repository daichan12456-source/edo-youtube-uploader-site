Edo YouTube Uploader

ホーム プライバシーポリシー 利用規約
Edo YouTube Uploader は、制作者本人が自分の YouTube チャンネルを操作するためだけに使う 個人用ツールです。制作者本人以外の利用者はおらず、第三者の情報を取得することはありません。 サーバーを持たず、すべての処理は本人の Windows パソコン上で完結します。

1. 取得する情報

本ツールは Google アカウントでの認可（OAuth 2.0）により、以下の権限（スコープ）を要求します。 要求するのは、本ツールを実行する本人のアカウントに対してのみです。

スコープ用途
https://www.googleapis.com/auth/youtube.upload 本人のチャンネルに動画ファイルをアップロードするため。
https://www.googleapis.com/auth/youtube.readonly アップロード先のチャンネル名とチャンネル ID を確認し、アップロードした動画のタイトル・説明文・公開設定・公開予定日時・処理状態が設定どおりかを読み取って検証するため。
https://www.googleapis.com/auth/youtube.force-ssl 検証の結果、自分がアップロードした動画のタイトル・説明文・タグが設定と食い違っていた場合に、それを修正するため。このスコープは、その機能を明示的に有効にして認可したときにのみ要求します。公開設定（非公開・限定公開・公開）の変更には使用しません。
https://www.googleapis.com/auth/yt-analytics.readonly 公開後に、本人のチャンネルの動画ごとの表示回数・クリック率・視聴維持率を読み取り、サムネイルや題名を見直す参考にするため。読み取り専用で、変更は行いません。この機能は別の操作で個別に認可したときにのみ使用し、認可は上記3つとは別の場所に分けて保存します。
最後の yt-analytics.readonly は、同じ OAuth クライアントから要求されうるため記載しています。 この分析機能は現在無効に設定されており、本人が明示的に有効にして改めて認可しないかぎり、 このスコープは要求されず、分析データも取得しません。

認可の結果として保存される情報

  • Google が発行するアクセストークンおよびリフレッシュトークン
  • アップロード先として確認したチャンネル名とチャンネル ID
  • アップロードした動画の ID、公開予定日時、検証結果（二重アップロードを防ぐための記録）
  • 分析機能を有効にした場合のみ、本人のチャンネルの動画ごとの表示回数・クリック率・視聴維持率

氏名、メールアドレス、連絡先、支払い情報、閲覧履歴、位置情報は取得しません。

2. 情報の利用目的

取得した情報は、次の目的にのみ利用します。

  • 本人が制作した動画を、本人のチャンネルに非公開でアップロードすること
  • タイトル・説明文・タグ・公開予定日時を、あらかじめ用意した設定どおりに登録すること
  • 登録内容が設定どおりかを確認し、食い違いがあれば修正すること
  • 同じ動画を二重にアップロードしないよう照合すること
  • 分析機能を有効にした場合のみ、本人のチャンネルの視聴データを読み取り、 サムネイルや題名を見直す参考にすること

広告、プロファイリング、機械学習モデルの学習、統計の作成など、上記以外の目的には一切利用しません。

3. 認証情報の保存方法

  • トークンは、Windows の DPAPI によって暗号化し、そのパソコンの当該 Windows ユーザーだけが復号できる形で保存します。
  • 保存場所は、本人のパソコン内のローカル アプリケーション データ領域です。プログラムの ソースコードを置いた場所の外に保存し、バージョン管理の対象に含めません。
  • トークン、クライアント シークレット、その他の認証情報を、画面表示、ログ、レポート、 バージョン管理のいずれにも出力しません。
  • 本ツールはサーバーを持ちません。情報が送られる先は Google の API のみで、 それ以外のネットワーク送信は行いません。

4. 第三者への提供

取得した情報を、第三者に販売、譲渡、貸与、開示することはありません。 広告事業者、分析事業者、データ ブローカーを含め、いかなる第三者にも提供しません。 人による閲覧も行いません。

5. Google API Services User Data Policy への適合

本ツールによる Google API から受け取った情報の利用および他者への移転は、 Google API Services User Data Policy （限定的使用に関する要件を含む）に準拠します。

本ツールは、機能の実現に必要な最小限の権限のみを要求します。将来の機能のために 先回りして権限を要求することはありません。取得した情報は、本ページに記載した 利用者向けの機能を提供する目的にのみ使用し、広告配信、ターゲティング、 与信判断、データの販売には一切使用しません。

Edo YouTube Uploader's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. 保存期間と削除の方法

  • トークンは、本人が削除するか、Google 側で権限を取り消すまで保存されます。
  • 権限の取り消しは、Google アカウントの サードパーティ アプリとサービス の画面から、いつでも本人が行えます。
  • 保存されたトークンのファイルを削除すれば、保存された認証情報は失われます。 次回以降、改めて認可し直さないかぎり本ツールは動作しません。
  • アップロードした動画そのものの削除は、YouTube Studio から本人が行います。

7. 安全管理

  • 通信はすべて HTTPS で行われます。
  • 認可の手続きは、本人のパソコン上で一時的に待ち受けるローカル アドレス （127.0.0.1）で受け取り、外部に公開しません。
  • 動画は必ず非公開としてアップロードされ、自動的に一般公開されることはありません。

8. 適用される規約

本ツールの利用には、YouTube の利用規約および Google プライバシーポリシーが適用されます。
